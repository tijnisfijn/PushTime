Pick a target and hit Resolve
Works whether the text is a Text Block / Text Animator source on a clip, or added as an effect on a clip or a layer. Resolve scans the target and lists every text parameter it finds; pick the one you want to drive. The OSC address is only auto-built for a clip source (verified format); for effects use Arena's OSC Shortcut mode.
off
Listens over Arena's WebSocket (same host, port 8080) for the target clip. Connecting it starts the timer; disconnecting it stops and resets. Only available when the target is a clip. Mode, duration and pause stay here.
